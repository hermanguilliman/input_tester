# Guilliman Input Diagnostics

Веб-приложение для диагностики устройств ввода: **мыши**, **клавиатуры**, **тачскрина**, **геймпада**, **микрофона** и **камеры**. Работает полностью в браузере, без сборки и зависимостей — достаточно открыть `index.html`.

Доступно на [input.guilliman.ru](https://input.guilliman.ru). Тёмная и светлая темы, интерфейс на трёх языках (русский, английский, 中文).

## Возможности

### 🖱️ Мышь
- Тестирование всех 5 кнопок (ЛКМ, СКМ, ПКМ, боковые Back/Forward).
- Определение **двойных срабатываний** (chatter/дребезг) с настраиваемым порогом (100–600 мс).
- **CPS** — количество кликов в секунду (скользящее окно 1 с).
- **min/max интервал** между кликами по каждой кнопке.
- Визуализация нажатий на SVG-мыши и трекер движения с корректным расчётом скорости (px/s по реальному Δt).
- Тест колеса прокрутки с индикацией направления.
- Лог событий.

### ⌨️ Клавиатура
- Визуальная QWERTY-раскладка (ANSI / US) с подсветкой нажатых клавиш в реальном времени.
- **N-Key Rollover (NKRO)** — счётчик одновременно зажатых клавиш и максимум за сессию.
- Счётчики: всего нажатий, уникальных клавиш, нажатий на каждую клавишу.
- Отображение `code` и `keyCode` последней клавиши.
- Отметка уже протестированных клавиш, снятие «залипаний» при потере фокуса окна.
- Лог событий.

### 🖐️ Тачскрин
- Отслеживание всех касаний: количество активных, максимально одновременных, всего за сессию.
- Распознавание жестов: Tap, Double Tap, Long Press, Swipe, Pinch, Zoom.
- Координаты всех активных точек на экране.
- Режим **рисования** пальцем: разноцветные штрихи (hsl-палитра), ластик.
- Полноэкранный режим рисования с чёрным фоном и сеткой, кнопка выхода.
- **Тактильная отдача** (haptic feedback) при каждом касании (если поддерживается устройством и браузером).

### 🎮 Геймпад
- Поддержка [Gamepad API](https://developer.mozilla.org/docs/Web/API/Gamepad_API), опрос через `requestAnimationFrame`.
- Автоматическое определение подключения/отключения.
- Визуализация всех кнопок с силой нажатия (аналоговые триггеры LT/RT).
- Два стика с позицией по осям.
- Тест вибрации (если поддерживается контроллером и браузером).

### 🎤 Микрофон
- Запуск через `getUserMedia({ audio: true })`.
- Индикатор уровня звука в реальном времени (AnalyserNode, AudioContext).
- Пиковый уровень, количество клиппингов, длительность записи.
- Режим **авто-мьют** (включён по умолчанию) для предотвращения обратной связи.
- Отображение информации об устройстве.

### 📷 Камера
- Запуск через `getUserMedia({ video: true })`.
- Прямой эфир с FPS-счётчиком (через `requestAnimationFrame`).
- Снимок экрана (screenshot to PNG).
- Наложение сетки «правило третей».
- Отображение информации об устройстве и разрешении.

### Общее
- 🌗 Тёмная / светлая тема (по умолчанию тёмная), выбор сохраняется.
- 🌐 Языки: **русский** (основной), английский, китайский. Выбор сохраняется.
- Мобильная адаптация: перегруппировка вкладок (тачскрин — первым), скролл, крупные кнопки.
- Настройки хранятся в `localStorage` браузера.

## Запуск

Особой установки не требуется:

1. Скачайте/клонируйте репозиторий.
2. Откройте `index.html` в браузере (двойной клик).

Приложение использует классические скрипты, поэтому работает и по протоколу `file://`, без локального сервера. При желании можно запустить любой статический сервер, например:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

> Примечание: для теста геймпада браузер требует нажать любую кнопку на контроллере (политика Gamepad API). Вибрация доступна не во всех браузерах/контроллерах. На Firefox Mobile тактильная отдача может быть заблокирована настройками приватности — разрешите вибрацию в настройках сайта.

### Архитектура

Каждый модуль — самодостаточный IIFE, публикующий один глобальный объект (`I18n`, `Theme`, `Router`, `MouseTest`, `KeyboardTest`, `TouchTest`, `GamepadTest`, `MicTest`, `CameraTest`). `main.js` подключается последним и инициализирует всё приложение. Порядок подключения скриптов в `index.html` важен: модули загружаются до `main.js`.

Все цвета вынесены в CSS-переменные и переключаются через атрибут `data-theme` на `<html>`. Canvas и SVG читают актуальные цвета из темы.

## Локализация

Строки интерфейса помечены атрибутом `data-i18n="ключ"` и берутся из словаря в `js/i18n.js`. Чтобы добавить язык:

1. Добавьте объект в `DICT` (например, `de: { ... }`) в `js/i18n.js`.
2. Добавьте `<option value="de">DE</option>` в селектор языка в `index.html`.

## Технологии

Чистые HTML, CSS и JavaScript (ES6+), без фреймворков и сборщиков. Внешние ресурсы — только шрифты Google Fonts и иконки Font Awesome (через CDN).
